# Tetris Battle: DS4F vs Grok 4.6 vs GLM-5.3 vs Qwen3.8-27b

Four AI models race to build the most awesome, visually impressive Tetris — each in a *single, self-contained HTML file*.

## The Prompt

Every file is the untouched, single-shot output of the same prompt:

> **"Build me the most awesome, visually impressive Tetris in single html. Make a real effort to make it work properly in single shot and look the best. High res, NO AI SLOP colors. A real modern Tetris same. Be thorough, don't make mistakes."**

No fixes, no tweaks — this is a straight head-to-head of what each model can produce in one shot.

## How to Play

Open the [arena index](https://miaai-lab.github.io/Tetris-Battle-DS4F-Grok46-GLM-5.3-Qwen38-27b/) — each Tetris opens in its own new tab so you can play them all side by side.

Prefer to jump straight in? Just open any of the four HTML files directly in a browser. There is no build step, no server, and no dependencies — each file is fully self-contained.

## Rules of the Battle

- Same prompt, same model settings? No — each model got the identical prompt text.
- No human edits to gameplay, visuals, or code after generation.
- Winner is decided by: visual impressiveness, faithful Tetris mechanics, and lack of "AI slop".
